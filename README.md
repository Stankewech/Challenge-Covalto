### Información General
***
Este es el proyecto principal que funciona como un portafolio web para mostrar tres retos diferentes de pruebas de software (QA). A través de una página de inicio, puedes navegar y explorar cada uno de los ejercicios resueltos:

- **Prueba 1:** Revisión de una página web estática para encontrar y corregir errores visuales y de código, generando una lista con los detalles encontrados.
- **Prueba 2:** Uso de scripts en Python para conectarse a la API de Rick and Morty, revisando que los datos, tiempos de respuesta y estados sean correctos.
- **Prueba 3:** Automatización de un proceso de compra completo en una tienda virtual de prueba usando Selenium, respaldado por una lista detallada de casos de prueba.


## Tecnologías
***
Lista de tecnologías globales que usamos en este repositorio:
- [HTML5](https://developer.mozilla.org/es/docs/Web/HTML): Para armar la estructura del portafolio principal y conectar los proyectos.
- [CSS3](https://developer.mozilla.org/es/docs/Web/CSS): Para el diseño, colores y asegurar que la página se vea bien en cualquier pantalla.
- [JavaScript](https://developer.mozilla.org/es/docs/Web/JavaScript): Para controlar el menú de navegación y botones interactivos.
- [Python 3](https://www.python.org/): Lenguaje utilizado para resolver las pruebas 2 y 3.
- [Selenium](https://www.selenium.dev/): Herramienta utilizada en la prueba 3 para controlar el navegador de forma automática.

## Instalación
***
Una pequeña guía para empezar y navegar por todos los proyectos.

Primero, descarga el código a tu computadora:
```
$ git clone https://github.com/tu-usuario/tu-repo.git
$ cd tu-repo
```

Para ver el portafolio principal que conecta todo, simplemente abre el archivo principal en tu navegador:
```
$ start index.html
```

Nota: Desde esa página principal podrás hacer clic en los botones para ir a la Prueba 1, Prueba 2 y Prueba 3. Si quieres correr los códigos de Python, recuerda revisar las instrucciones de instalación dentro de las carpetas de las pruebas 2 y 3.
