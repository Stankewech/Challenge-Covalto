# Editorial Challenge Portfolio

Sitio estático hecho con HTML, CSS y JavaScript. Está preparado para publicarse en GitHub Pages.

## Personalización rápida

1. Abre `index.html`.
2. Busca y reemplaza:
   - `TU-USUARIO` por tu nombre de usuario de GitHub.
   - `TU-REPO-1`, `TU-REPO-2` y `TU-REPO-3` por los nombres reales de tus repositorios.
   - Los títulos, descripciones, tecnologías y puntos clave por los de tus proyectos.
   - `TU-CORREO` por tu correo de contacto.
3. Cambia o elimina los enlaces de demo si todavía no tienes demos publicadas.
4. Si quieres que el sitio no dependa de Google Fonts, elimina los dos enlaces de Google Fonts en el `<head>` y utiliza las fuentes de respaldo del CSS.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo, por ejemplo `challenge-portfolio`.
2. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, luego guarda.
6. Espera a que GitHub Pages publique el sitio y abre la URL que aparece en esa sección.

## Importante

Los tres proyectos y sus tecnologías del diseño son ejemplos de contenido. Sustitúyelos por los datos reales de tus repositorios. Las vistas técnicas son elementos visuales hechos con CSS, no capturas reales de tus aplicaciones.
